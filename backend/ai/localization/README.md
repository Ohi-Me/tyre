# backend/ai/localization

TypeScript wrappers, types, and SDK clients for the `localization` capability of the
Python AI gateway (`backend/ai/gateway/`).

This folder holds TS code consumed by the Next.js app and route handlers
(e.g., `frontend/web/app/api/v1/localization/`). The actual Python implementation
lives in `backend/ai/gateway/app/ai/localization/`.
