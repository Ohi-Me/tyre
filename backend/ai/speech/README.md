# backend/ai/speech

TypeScript wrappers, types, and SDK clients for the `speech` capability of the
Python AI gateway (`backend/ai/gateway/`).

This folder holds TS code consumed by the Next.js app and route handlers
(e.g., `frontend/web/app/api/v1/speech/`). The actual Python implementation
lives in `backend/ai/gateway/app/ai/speech/`.
